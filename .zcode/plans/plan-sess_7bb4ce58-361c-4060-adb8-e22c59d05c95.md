## 目标
把 `search` 从"搜索内置 26 部番库"升级为"实时调用 AniList API 搜索全网番剧"；`add` 支持通过 API 的 id 添加。其余功能（列表/进度/打分/持久化）完全不动。

## 为什么选 AniList + WinINET
- Jikan（MyAnimeList 接口）实测 504 故障；AniList 实测正常，返回字段齐全（id、多语言标题、集数、季度、类型）
- WinINET 是 Windows 自带库，用 g++ 加 `-lwininet` 即可，**不需要安装任何第三方依赖**（对比 libcurl/cpp-httplib 都要配 OpenSSL，新手地狱）

## 新增文件（2 个模块，各含 .hpp/.cpp）

**1. `src/http.hpp` / `src/http.cpp`** — 网络请求封装
- `std::string httpPost(url, body, contentType)`：用 WinINET 发 HTTPS POST，返回响应文本
- 约 40 行：InternetOpen → InternetConnect → HttpOpenRequest → HttpSendRequest → InternetReadFile

**2. `src/anilist.hpp` / `src/anilist.cpp`** — AniList 客户端
- `std::vector<Anime> searchAnime(keyword)`：GraphQL 搜索（perPage=5）
- `bool fetchAnimeById(id, Anime& out)`：按 id 获取单部（用于 add）
- 字段映射：`id`→数字 id、`titleZh`←英文标题（无则罗马音）、`titleEn`←罗马音、`totalEpisodes`←集数（null 记 0）、`season`←年份+季度（如 "2023 FALL"）、`genres`←类型
- 用 nlohmann/json 构造 GraphQL 请求体和解析响应（复用现有库，不引新依赖）

## 修改文件

**3. `src/main.cpp`**（只动两个命令）
- `search`：优先调 API；**API 失败时自动回退到内置番库**并提示"离线模式"——保证断网也不崩
- `add`：先在本地番库精确匹配（离线可用）；匹配不到且是数字 id 时，从 API 拉取添加；都不是则提示先 search
- 其余命令（list/watch/rate/…）零改动

**4. `build.bat`**：编译命令加 `-lwininet`

**5. `README.md`**：功能特性、技术栈、命令速查更新为"在线 API 搜索"

## 关键兼容性保证
- **`Anime` 结构体不加新字段**，`mylist.json` 格式不变 → 你现有的追番数据加载不受影响
- `catalog.hpp` 保留，只作为离线回退用
